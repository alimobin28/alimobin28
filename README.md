## 👋 About Me

I'm a Computer Science undergraduate at **FAST-NUCES**, building AI systems that hold up outside a Jupyter notebook — not toy demos, but pipelines with real architecture, benchmarking, and error handling behind them.

My work centers on **Retrieval-Augmented Generation, LLM applications, computer vision, and NLP**. I've designed and implemented 8 different RAG architectures end-to-end (Naive, HyDE, CRAG, Graph, Hybrid, Adaptive, Agentic, Multimodal), benchmarked 8+ OCR engines for production accuracy/speed trade-offs, and built retrieval systems grounded in published research rather than tutorials.

I read research papers and implement them. I benchmark before I choose a model or a tool. I care as much about system design — chunking strategy, retrieval pipelines, API structure — as I do about the model itself.
